How to use

Four simple steps

  1. 1
    Run the tool and select your combo file (.txt format).
  2. 2
    Choose the number of threads (1–200) for your system.

Performance tips

Get the most out of AntiPublic

  • Optimal Thread Count. Start with 50 threads and adjust based on your system's performance.
  • File Size. For best results, process files under 1 GB at a time.
  • Regular Updates. Always use the latest version for best performance and features.
